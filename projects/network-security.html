NETWORK SECURITY CASE STUDY

Secure Network Configuration & Testing

A practical network-security project focused on implementing and validating Layer 2 defensive controls within a controlled Cisco Packet Tracer environment.

Cisco Packet Tracer VLAN Security Port Security DHCP Snooping BPDU Guard

PROJECT OVERVIEW

Strengthening a switched network against common Layer 2 attacks.

This project involved designing and configuring security controls on Cisco switches to reduce common risks associated with unauthorized devices, rogue DHCP servers, VLAN misuse and malicious switching activity.

The work was performed in an authorized laboratory environment using Cisco Packet Tracer, followed by verification commands and connectivity testing to confirm that the configured security controls operated as intended.

Project Type

Network Security Laboratory

Environment

Cisco Packet Tracer

Focus

Layer 2 Security

Role

Configuration, Testing & Verification

01 / OBJECTIVES

What the project aimed to achieve.

Network Segmentation

Separate users and management resources using dedicated VLANs.

Access Protection

Restrict unauthorized devices from gaining network access through switch ports.

DHCP Protection

Reduce the risk of rogue DHCP services using DHCP Snooping.

Layer 2 Protection

Protect access ports from malicious or unauthorized spanning-tree participation.

02 / SECURITY IMPLEMENTATION

Controls implemented during the laboratory.

01

VLAN Segmentation

Created dedicated VLANs for administrative users, sales users, management traffic, native trunk traffic and unused interfaces.

02

Black-Hole VLAN

Assigned unused switch interfaces to an isolated VLAN to reduce the risk of unauthorized physical network access.

03

Secure Trunk Configuration

Configured trunk interfaces explicitly and used a dedicated native VLAN rather than relying on insecure default behavior.

04

Port Security

Restricted access ports to approved MAC addresses and tested how the switch responded to unauthorized devices.

05

BPDU Guard

Applied BPDU Guard on edge interfaces to protect the spanning-tree topology from unexpected switching devices.

06

DHCP Snooping

Enabled DHCP Snooping and differentiated trusted and untrusted interfaces to reduce rogue DHCP attack opportunities.

03 / TESTING & VERIFICATION

Security controls were validated after configuration.

Configuration Verification

Cisco IOS verification commands were used to confirm VLAN membership, trunk configuration, port-security status and DHCP Snooping state.

Connectivity Testing

Connectivity tests confirmed that legitimate hosts maintained expected communication while segmentation policies remained active.

Unauthorized Device Testing

Port-security behavior was examined using devices with unauthorized MAC addresses to verify policy enforcement.

05 / SECURITY VALUE

What these controls protect against.

Unauthorized network access
Rogue DHCP servers
VLAN misuse
Spanning-tree attacks
Unauthorized switching devices

06 / KEY TAKEAWAYS

What I learned from the project.

The project strengthened my understanding that network security does not depend on a single configuration command. Effective Layer 2 security requires segmentation, interface hardening, trusted-device control and continuous verification working together.

It also reinforced the importance of testing security controls after configuration rather than assuming that the presence of a command means the protection is operating correctly.
