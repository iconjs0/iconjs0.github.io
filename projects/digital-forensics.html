DIGITAL FORENSICS CASE STUDY

Evidence Acquisition, File-System Analysis & Recovery

A practical digital-forensics investigation focused on acquiring forensic images, verifying evidence integrity, analysing FAT file-system structures and examining deleted data in a controlled laboratory environment.

FTK Imager FAT12 / FAT16 / FAT32 Hash Verification Hex Analysis Deleted File Recovery

PROJECT OVERVIEW

Preserving and analysing digital evidence correctly.

This project focused on fundamental digital-forensics procedures used to preserve, validate and analyse storage evidence without altering the original data.

The investigation included forensic image creation, integrity verification using cryptographic hashes, examination of FAT file-system structures and analysis of deleted files and unallocated areas.

Project Type

Digital Forensics Laboratory

Primary Tool

FTK Imager

File Systems

FAT12 / FAT16 / FAT32

Focus

Evidence Integrity & File-System Analysis

01 / INVESTIGATION OBJECTIVES

What the forensic exercise aimed to demonstrate.

Evidence Acquisition

Create forensic images while preserving the original evidence source.

Integrity Verification

Use cryptographic hashes to verify that acquired forensic images remain unchanged.

File-System Analysis

Examine FAT structures including reserved areas, FAT tables, root directories and data regions.

Deleted Data Analysis

Examine deleted files, unallocated space and recoverable artifacts.

02 / FORENSIC WORKFLOW

Investigation process used during the laboratory.

01

Prepare the Evidence Source

Storage media and laboratory evidence were prepared for analysis while maintaining a clear separation between original evidence and working copies.

02

Create Forensic Images

Forensic images were acquired using FTK Imager so analysis could be performed on copies rather than modifying the original evidence.

03

Verify Evidence Integrity

MD5 and SHA-256 hashes were recorded and compared to confirm that the forensic images remained consistent after acquisition.

04

Examine FAT Structures

Boot-sector parameters were examined to identify important FAT file-system regions and calculate their locations within the image.

05

Analyse Deleted Data

Deleted entries, file metadata, unallocated space and remaining file contents were examined to understand how recoverable evidence can persist.

06

Document Findings

Evidence locations, hash values, observations and recovered artifacts were documented as part of the forensic analysis process.

03 / TECHNICAL ANALYSIS

Understanding the FAT file-system structure.

Boot Sector

Parameters such as bytes per sector, sectors per cluster, reserved sectors and FAT count were examined from the boot record.

FAT Tables

File Allocation Tables were examined to understand how clusters are linked and how file allocation information is maintained.

Directory Entries

Root-directory and file entries were examined for filenames, attributes, timestamps and deleted-entry indicators.

04 / TECHNICAL EVIDENCE

Evidence from acquisition and analysis.

EVIDENCE 01

Forensic Image Acquisition

Evidence acquisition using FTK Imager in the controlled laboratory environment.

EVIDENCE 02

Hash Verification

Recorded cryptographic hashes used to verify evidence integrity.

EVIDENCE 03

FAT Structure Analysis

Examination of file-system structures and forensic offsets.

EVIDENCE 04

Deleted File Analysis

Examination of deleted file artifacts and recoverable information within the image.

05 / FORENSIC VALUE

What the exercise demonstrates.

Evidence integrity
Deleted artifact persistence
Low-level file-system analysis
Forensic documentation
Repeatable forensic examination

06 / KEY TAKEAWAYS

What I learned from the investigation.

The laboratory strengthened my understanding that digital forensics begins with evidence preservation. Analysis becomes unreliable if the integrity of the evidence cannot be demonstrated.

It also showed how file deletion does not necessarily remove all useful information immediately. File-system structures, metadata and unallocated storage can retain valuable forensic artifacts after deletion.
